# Google Remade ×100000 💧

Ремейк главной страницы Google в стиле **Liquid Glass** — в 100000 раз лучше оригинала (примерно).

![preview](https://img.shields.io/badge/style-liquid%20glass-4285F4)

## Запуск

Никакой сборки — чистые HTML/CSS/JS:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Что внутри

- 🫧 **Liquid glass повсюду** — backdrop-blur, насыщенность, спекулярные блики по кромкам, блик, следующий за курсором
- 🌊 **Живой фон** — плавающие кляксы в цветах Google, аврора, зерно плёнки, клякса-хамелеон за мышью
- 🔍 **Рабочий поиск** — live-подсказки, история запросов (localStorage), голосовой ввод (Web Speech API), умный URL-детект
- ⌨️ **Шорткаты** — `/` фокус на поиске, `↑↓` навигация по подсказкам, `Esc` сброс
- 🎨 **Тёмная и светлая темы** + 🌐 **RU/EN** — запоминаются
- 🎉 **Пасхалка** — нажми на бейдж «×100 000»
- ♿ `prefers-reduced-motion`, клавиатурные фокус-кольца, адаптив под мобилки
