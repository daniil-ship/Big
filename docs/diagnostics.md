# Диагностики bigc

Компилятор печатает ошибки в `stderr` в виде

```
error: <сообщение> [<имя>]
```

и завершается с кодом **1**, не создавая выходной файл. Все проверки
выполняются на этапе семантического анализа после полного разбора
(ошибки лексера/парсера приводят к пропуску токенов и последующим
семантическим ошибкам).

## Список диагностик

| Условие | Сообщение |
|---------|-----------|
| `let x: i32 = "строка"` (литерал не совпадает с аннотацией) | `error: type mismatch in declaration of: x` |
| использование необъявленной переменной | `error: undefined variable: y` |
| вызов неизвестной функции | `error: undefined function: foo` |
| неверное число аргументов у пользовательской функции | `error: wrong number of arguments for: foo` |
| у `print`/`println` больше одного аргумента | `error: print/println expects 0 or 1 argument` |
| повторное объявление функции | `error: redefinition of: main` |
| в программе нет `func main()` | `error: function main() not found` |
| входной файл не открывается | `error: cannot open file: <путь>` (сразу, до разбора) |
| не хватает памяти арены | `out of memory` (аварийное завершение) |
| не удалось записать результат | `cannot write file: <путь>` |
| нет входного файла в аргументах | `no input file given (expected <file.bg>)` |

Несколько ошибок не прерывают анализ: компилятор продолжает проверку и
сообщает все найденные проблемы за один запуск (см. `examples/error_demo.bg`):

```
$ bigc.exe examples\error_demo.bg
error: type mismatch in declaration of: x
error: undefined variable: y
(код выхода 1)
```

## Пример: error_demo.bg

```big
func main() -> i32 {
    let x: i32 = "привет";  // ошибка: тип строка вместо i32
    print(y);               // ошибка: переменная y не объявлена
    let a: i32 = 5;
    if a > 0 {
        print("внутри if");
    }
    return a;
}
```

## Примечания

- Имена в диагностиках печатаются как есть (байты исходника, без
  перекодировки) — кириллические идентификаторы отобразятся корректно
  в консоли с UTF-8.
- Номера строк/колонок в сообщениях пока не выводятся — только имя
  сущности. Формат выбран совместимым с будущим расширением
  (`--> файл:строка:колонка`).
- Предупреждения (например, о неиспользуемых переменных) не реализованы:
  `let unused: i32 = 123;` в `error_demo.bg` ошибкой не считается.
