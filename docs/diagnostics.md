# Коды диагностики Big

> Формат: `level[CODE]: сообщение` + `--> file:line:col` + `|` + `line_text` + `^` + `= help:` / `= note:`  
> Цвета: `error` красный, `warning` жёлтый, `info` голубой. Каждый `help` — конкретное действие, не «исправьте ошибку».

## Уровни

- **error[E…]** — компиляция прерывается (но остальные стадии всё равно прогоняются, чтобы показать больше ошибок)
- **warning[W…]** — компиляция продолжается, но стоит исправить
- **info[I…]** — подсказки, не требуют действия

## LEX (E10xx / W10xx)

| Код | Сообщение | Когда | Help |
|-----|-----------|-------|------|
| `E1000` | `неизвестный символ \`c\` (U+XXXX)` | символ не входит в ASCII/UTF-8 токены | уберите символ или заэкранируйте в строке |
| `E1001` | `незакрытая строковая литерала — пропущена закрывающая \`"` | `"` без пары до конца строки/файла | добавьте `"` в конце строки |
| `E1002` | `незакрытый блочный комментарий \`/*\` — пропущен \`*/\`` | `/*` без `*/` до `EOF` | добавьте `*/` |
| `W1003` | `неизвестная escape-последовательность \\\x` | `\q`, `\x` кроме `\" \\ \n \t \0 \r` | используйте `\\`, `\"`, `\n`, `\t`, `\0` |

## PARSE (E20xx / W20xx)

| Код | Сообщение | Когда | Help |
|-----|-----------|-------|------|
| `E2000` | `неожиданный токен \`…\` в глобальной области — ожидалась функция \`func\` или константа \`const\`` | `let` вне `func` и т.п. | оберните в `func main() { … }` |
| `E2001` | парсер ждёт `;`/`}` | пропущен `}` | добавьте `}` в конце блока |
| `W2001` | `пропущена \`;\" после объявления переменной` | `let x = 5` без `;` | добавьте `;` |
| `W2002` | `пропущена \`;\" в конце объявления константы` | `const C = 5` без `;` | добавьте `;` |
| `E2003` | `ожидался тип (например \`i32\`, \`i64\`, \`bool\`, \`str\`)` | `let x: foo` | напишите `i32`/`i64`/`bool`/`str` |
| `E2004` | `ожидалось имя параметра` | `func f(,)` | добавьте `name: type` |
| `E2005` | `в \`for\` ожидается диапазон \`..\`, например \`0..10\`` | `for i in 5` | напишите `for i in 0..10` |
| `E2006` | `неожиданный токен \`…\` в выражении` | `let x = @` | проверьте выражение |

## SEMA (E30xx / W30xx / I30xx)

| Код | Сообщение | Когда | Help |
|-----|-----------|-------|------|
| `E3000` | `функция \`foo\` уже определена` | дубли `func foo` | переименуйте вторую |
| `E3001` | `переменная \`x\` уже объявлена в этой области` | `let x; let x;` | используйте другое имя или присваивание `x = …` |
| `W3002` | `неиспользуемая переменная \`x\`` | `let x = 5` без `read` | переименуйте в `_x` или `print(x)` |
| `W3003` | `неизвестный тип \`foo\` — будет использован \`i32\`` | `let x: foo` | используйте `i32`/`i64`/`bool`/`str` |
| `W3004` | `функция \`…\` должна вернуть значение типа \`…\` но не все пути возвращают` | `func f() -> i32 { if … {return 1} }` | добавьте `return` в конце или `else` |
| `E3005` | `в файле нет ни одной функции` | пустой `file.bg` | добавьте `func main() -> i32 { return 0; }` |
| `E3006` | `несоответствие типов: переменная \`x\` объявлена как \`i32\`, но инициализируется значением типа \`str\`` | `let x: i32 = "hi"` | поменяйте тип на `str`, или присвойте `i32` |
| `W3005` | `не удалось вывести тип переменной \`x\` — используется \`i32\` по умолчанию` | `let x;` без типа и без инициализатора | добавьте тип `: i32` или `= 0` |
| `I3002` | `переменная \`x\` затеняет переменную из внешней области` | `let x; { let x; }` | переименуйте внутреннюю или используйте `_x` |
| `E3007` | `неизвестная переменная \`x\` — присваивание несуществующей` | `x = 5` без `let` | объявите `let x: i32 = 5;` |
| `E3008` | `несоответствие типов в присваивании \`x = …\`: ожидается \`T\`, найдено \`U\`` | `let x: i32 = 1; x = "hi"` | присвойте `i32` |
| `W3006` | `условие \`if\` имеет тип \`…\`, ожидается \`bool\`` | `if 42 {…}` | напишите `if x > 0` или `if x != 0` |
| `E3009` | `тип возвращаемого значения не совпадает: ожидается \`T\`, найдено \`U\`` | `func f()->i32 {return "hi"}` | верните `i32` |
| `W3007` | `функция возвращает значение, но сигнатура не указывает тип возврата` | `func f(){return 1}` | добавьте `-> i32` |
| `E3010` | `ожидалось возвращаемое значение типа \`T\`` | `func f()->i32 {return;}` | `return 0` |
| `W3008` | `выражение как statement — его значение нигде не используется` | `x + 1;` строка без эффекта | присвойте `let y = x+1;` или уберите |
| `E3011` | `неизвестный идентификатор \`x\`` | `print(y)` где `y` нет | объявите `let y` или исправьте имя |
| `E3012` | `неизвестная функция \`foo\`` | `foo()` нет такой | проверьте имя или добавьте `func foo` |
| `E3013` | `неверное количество аргументов для \`foo\`: ожидается N, передано M` | `max(1)` где `max(a,b)` | передайте все аргументы |
| `E3014` | `тип аргумента не совпадает для параметра \`p\`: ожидается \`T\`, найдено \`U\`` | `max("hi", 2)` | передайте `i32` |
| `W3009` | `оператор \`!\` применяется к \`T\`, обычно используется для \`bool\`` | `!42` | используйте `!cond` где `cond: bool` |
| `W3010` | `смешанные числовые типы \`i32\` и \`i64\` в операции \`+\`` | `a:i32 + b:i64` | приведите к одному типу |
| `E3015` | `оператор \`op\` нельзя применить к типам \`A\` и \`B\`` | `"hi" + 5` | используйте одинаковые типы |
| `W3000` | `отсутствует функция \`main\` — точка входа не найдена` | файл без `main` | добавьте `func main() -> i32 { … }` |
| `I3001` | `функция \`main\` — точка входа программы` | найден `main` | info, ничего не делать |
| `E9999` | `слишком много аргументов (N) — максимум 4 в Big на данный момент` | `foo(1,2,3,4,5)` | разбейте вызов |
| `W4002` | `функция \`foo\` пока не генерирует код в bootstrap-компиляторе — будет заглушка \`return 0\`` | `func foo` не `main` | пока только `main` эмитит код |

### CLI / IO

| Код | Когда |
|-----|-------|
| `E0001` | `bigc` без аргументов — `error[E0001]: не указан входной файл` |
| `E0002` | файл не найден |
| `W0001` | расширение не `.bg` |
| `E4000/E4001/E5000` | внутренние ошибки CG/IO — с `note:` где искать |

## Примеры

### E3006 — типы

```big
func main() -> i32 {
    let x: i32 = "oops";
    return 0;
}
```
```
error[E3006]: несоответствие типов: переменная `x` объявлена как `i32`, но инициализируется значением типа `str`
 --> demo.bg:2:5
  |
2 |     let x: i32 = "oops";
  |     ^^^^^^^^^^^^^^^^^^^^^
  |
  = help: поменяйте тип на `str`, например `let x: str = "oops";`, или присвойте i32 `let x: i32 = 42;`
```

### W3002 — неиспользуемая переменная

```
warning[W3002]: неиспользуемая переменная `unused`
 --> demo.bg:4:9
  |
4 |     let unused: i32 = 5;
  |         ^^^^^^
  |
  = help: если переменная пока не нужна, переименуйте в `_unused` (с подчёркивания), или используйте её: `print(unused)`
```

### E3011 — неизвестный идентификатор

```
error[E3011]: неизвестный идентификатор `y`
 --> demo.bg:3:11
  |
3 |     print(y);
  |           ^
  |
  = help: проверьте написание, или объявите `let y: i32 = 0;` выше
```

## Как добавить новую диагностику

В `bigc.py`:
```python
diag("error","E30xx","сообщение", span,
     notes=["= note: почему"],
     helps=["= help: что сделать"])
```
- `span` — из `Token.span` или `Parser.span_from`
- Сообщение — коротко, на русском, с обратными кавычками `` `...` `` для кода
- `help` — всегда с примером кода: `` `let x: i32 = 42;` ``
- Цвета добавляются автоматически (`col()`), код — жирный.
