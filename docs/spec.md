# Спецификация языка Big

> Описывает то, что **реально** реализовано в компиляторе `src/bigc.asm`
> (чистый NASM, цель — только Windows 11 x64, PE64). Не планы — факт.

## 1. Лексика

### 1.1 Кодировка
Исходник — UTF-8. Строковые литералы — UTF-8, в PE пишутся байт-в-байт
(без BOM, без перекодировки). `print` в сгенерированной программе работает
через `WriteFile`, консоль переводится в кодовую страницу 65001
(`SetConsoleOutputCP`/`SetConsoleCP`), поэтому кириллица печатается как есть.

### 1.2 Токены

```
IDENT       [A-Za-z_][A-Za-z0-9_]*
INT         [0-9]+                 (десятичные, значение хранится как 64-бит)
STRING      " ... "                с экранированием
COMMENT     // ... до конца строки
            /* ... */              блочный, ненаселяемый, может занимать много строк
КЛЮЧ.СЛОВА  func let if else while for in return true false const use import
ТИПЫ        i32 i64 bool str
OPS         + - * / % == != < > <= >= && || ! = -> : .. , ; ( ) { }
```

Пробелы, переводы строк и комментарии игнорируются. Точка с запятой `;`
в конце оператора **необязательна** (можно ставить «как в Rust», можно без).

Экранирование в строках:
- `\n` → LF, `\t` → TAB, `\r` → CR, `\0` → NUL;
- любой другой `\x` сохраняется как есть (включая сам `\` и `x`).

### 1.3 Встроенные функции
`print`/`println` — не ключевые слова, а встроенные функции (intrinsics):
- `print(x)` — печатает аргумент без перевода строки;
- `println(x)` — печатает аргумент и добавляет `\r\n`;
- `println()` — просто печатает `\r\n`.

Аргумент: целое выражение `i32` (печатается десятичным числом, поддерживаются
отрицательные), строковый литерал, либо переменная типа `str`.

`use "..."` и `import "..."` на верхнем уровне принимаются и игнорируются.

## 2. Грамматика (упрощённо)

```
программа      = { объявление-функции }   // должна быть функция main
функция        = "func" IDENT "(" [параметры] ")" "->" тип блок
параметры      = параметр { "," параметр }
параметр       = IDENT ":" тип            // параметры-строки приводятся к указателю
тип            = "i32" | "i64" | "bool" | "str"
блок           = "{" { оператор } "}"
оператор       = let | присваивание | if | while | for | return | вызов-выражение
let            = "let" IDENT ":" тип [ "=" выражение ] [";"]
присваивание   = IDENT "=" выражение [";"]
if             = "if" выражение блок [ "else" (блок | if) ]
while          = "while" выражение блок
for            = "for" IDENT "in" выражение ".." выражение блок   // конец НЕ включается
return         = "return" [выражение] [";"]
выражение      = (по приоритетам, от слабых к сильным):
                 "||" → "&&" → "== !=" → "< > <= >=" → "+ -" → "* / %" → унарные "- !"
                 первичное: INT | STRING | true | false | IDENT | вызов | "(" выражение ")"
вызов          = IDENT "(" [аргументы] ")"
аргументы      = выражение { "," выражение }
```

## 3. Типы и переменные

- `i32`/`i64` — целые. Арифметика выполняется 64-битными инструкциями,
  значения хранятся в 8-байтовых слотах стека.
- `bool` — результат сравнений и `&&`/`||` (0/1), участвует в `if`/`while`.
- `str` — строковая переменная: пара (указатель на байты в `.rdata`, длина).
  Инициализируется строковым литералом: `let s: str = "текст";` — литерал
  один раз кладётся в `.rdata`, переменная хранит адрес и длину.
  `print(s)` печатает строку по сохранённой паре.

Константное свёртывание: выражение из целых литералов
(например, `3 - 5`) вычисляется на этапе семантического анализа.

## 4. Функции и рекурсия

- Пользовательские функции компилируются по-настоящему: параметры передаются
  через стек (слева направо), поддерживается полная рекурсия
  (`fib.bg`: `return fib(n - 1) + fib(n - 2);`).
- Каждая функция получает собственный кадр стека (`push rbp / mov rbp, rsp`),
  локальные переменные — в слотах `[rbp - 8*номер]`.
- `main() -> i32` обязательна: с неё начинается программа, её результат
  передаётся в `ExitProcess`.

## 5. Циклы

- `for i in a..b { ... }` — счётчик от `a` до `b`, **не включая** `b`
  (`for i in 0..5` печатает `0 1 2 3 4`). Границы — произвольные выражения,
  вычисляются один раз до цикла.
- `while cond { ... }` — условие перевычисляется на каждой итерации.
- `break`/`continue` не реализованы.

## 6. Семантические проверки

- неизвестная переменная → `error: undefined variable: <имя>`;
- неизвестная функция → `error: undefined function: <имя>`;
- неверное число аргументов → `error: wrong number of arguments for: <имя>`;
- `print`/`println` принимают 0 или 1 аргумент;
- `let x: i32 = "строка"` → `error: type mismatch in declaration of: x`;
- повторное объявление функции → `error: redefinition of: <имя>`;
- отсутствие `main` → `error: function main() not found`.

При наличии ошибок выходной файл не создаётся, код выхода компилятора — 1.

## 7. Поведение сгенерированной программы

- Точка входа выравнивает стек, ставит кодовую страницу консоли 65001,
  вызывает `main`, завершается через `ExitProcess(код main)`.
- `println` добавляет `\r\n` (CRLF) — стандарт Windows-консоли.
- Строки литералов размещаются в секции `.rdata` с завершающим NUL
  (NUL не входит в длину, передаваемую в `print`).
